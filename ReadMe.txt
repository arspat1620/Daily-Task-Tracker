This is an app I made as my first project to learn the CustomTkinter Library

Features:
-Updates the current Date and Time dynamically
-Asks for your name and remembers it
-Allows you to add, delete and edit tasks
-Tracks the number completed and remaining tasks  dynamically
-Displays a graph for your weekly progress
